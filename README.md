# Stocknix

Stocknix est un logiciel SaaS de gestion commerciale pour PME et TPE : gestion de stock, caisse POS, facturation, boutique en ligne et analytics.

## Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (base de données, auth, edge functions)

## Developpement local

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Site : https://www.stocknix.com
